## Tecnologias

HTML, CSS e JavaScript, sem frameworks. Publicado com GitHub Pages a partir da branch `main`.

```
├── *.html          páginas do site
├── css/style.css   estilos
├── js/script.js    menu mobile, animações e botões de copiar
└── images/         logo, fotos e QR codes
```

## Como rodar localmente

Abra o `index.html` no navegador ou, para servir a pasta:

```bash
python3 -m http.server
```

e acesse `http://localhost:8000`.
